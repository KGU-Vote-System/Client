## Introduction

**Took!** 은 교내 학생회 선거를 더욱 편리하게 할 수 있도록 돕는 블록체인 기반 전자 투표 웹 서비스에요.

- klaytn을 사용한 암호화를 통해 선거 과정 및 결과를 조작할 수 없도록, 정정당당한 선거가 가능하도록 해요.
- 관리자 모드에서 쉽게 투표를 생성하고 관리할 수 있으며, 공지사항을 작성 및 수정할 수 있어요.
- 학생 모드에서 지난 투표 결과를 확인하고, 투표에 참여하며 공지사항을 조회할 수 있어요.
- 카카오톡 소셜 로그인 및 lms와 연결된 로직을 통해 학생 인증을 거쳐 서비스에 가입해요.

## Getting Started (dev mode)

```
pnpm install
pnpm run dev
```
